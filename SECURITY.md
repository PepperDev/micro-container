# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Report vulnerabilities privately by emailing the maintainer or opening a draft security advisory on GitHub.

Do **not** report security issues via public issues or pull requests.

We aim to acknowledge receipt within 72 hours and provide a fix timeline within 5 business days.
